判据（任一条不满足即不合格）：
1. 最核心的那一个因素/结论放在最前面直接给出；不许先复述问题、先讲背景、先铺垫。
2. 用最简单最直白的话说，像跟人当面讲话；不许学术腔、不许术语堆砌。
   （术语本身就是用户要的信息时不算违规。）
3. 不旁生枝节：用户没问的方向不要主动展开；限定条件、例外情形不要全铺一遍。
4. 该带的出处一条不少：出现具体数值或文献结论时必须带可回查锚点（URL / DOI / PMID / arXiv / 文件路径 + 行号）。
   （这是用户明确要求的例外：省字不许省出处。）
5. 如果用户的问题里含多个问句，必须按「问题1+回答1、问题2+回答2」的顺序逐条对应。

例外：
- 用户这一轮明确要了「详细说 / 完整版 / 全部列出来」→ 长和细都不算违规，只看有没有答在点子上。
- 用户在赶时间、只要一个数或一个名字 → 多一句解释就算违规。
